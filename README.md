# ⬛⬜ Minimalist Habit Tracker - 365 Days

A web-based habit and productivity tracking application featuring a high-contrast, minimalist design. Built with absolute focus on performance, straightforward UX, and data privacy.

## ✨ Features

* **Yearly Heatmap (GitHub Style):** 365-day panoramic view to track your consistency.
* **Dynamic Routing (SPA):** Fluid navigation between the Overview Dashboard and detailed statistics for each activity without page reloads.
* **Analytical Filters:** Dynamic timeframe slicing by Year, Month, and Week for each individual habit.
* **100% Offline and Private:** All data is instantly saved in your browser's `localStorage`. Nothing is sent to third-party servers.
* **Backup System (Vault):** Export all your progress to a `.json` file and restore it on any other computer or browser.
* **Custom Modals:** Native browser pop-ups were replaced by integrated UI modals to maintain immersion.
* **Productivity Shortcuts:** Quick actions using the `Enter` key and a toggle system to log activities with 1 click.

## 🛠️ Tech Stack

* **HTML5** (Semantic structure)
* **CSS3** (Native variables, Advanced CSS Grid, Full-bleed layout, Responsive UI)
* **JavaScript (Vanilla)** (Complex DOM manipulation, JSON handling, Storage APIs)

## 🚀 How to Use

Since the project has no server dependencies (Node.js, external databases), installation is instant:

1. Clone this repository:
   `git clone https://github.com/YOUR_USERNAME/your-repo-name.git`
2. Open the project folder.
3. Double-click the `index.html` file to open it in your browser.
4. Add your activities and start tracking!

## 💡 Backup Tip
Remember to periodically export your `.json` file if you plan to clear your browser cache!
